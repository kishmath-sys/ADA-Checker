ADA CHECKER
Checks Word, PDF, web page, PowerPoint, Excel and Brightspace course export files against
WCAG 2.1 AA (the ADA Title II standard) and WCAG 2.2 AA. It lists what to change and what
to check by hand. It only reads your files and never changes them.


INSTALL (one time, about 5 minutes)

1. Unzip this folder somewhere it can stay, for example Documents\ADA Checker.
   Do not run it from inside the zip.
2. Double click Setup.bat.
   If Windows shows "Windows protected your PC", click More info, then Run anyway.
   That warning appears because the setup script is not signed by a company.
3. Setup installs Python if needed, installs the checking libraries, and creates shortcuts.
   ADA Checker opens when it finishes.


EVERYDAY USE

- Open ADA Checker from the desktop or Start menu.
- Check a file: pick one or more files.
- Check a folder: checks every supported file in the folder and its subfolders, then saves
  a summary spreadsheet and one report per file in Documents\ADA Checker Reports.
  Files that have not changed since the last check are skipped automatically.
- From File Explorer: right click a file or folder, Send to, ADA Checker.
- You can also drag files onto the window. Dragged files are checked from a copy, so use
  Check a file when you want Rescan and History to follow the original.

Each result has three lists:
  Fix in the file        found automatically, with where it is and how to fix it
  Check manually         needs your judgment; tick Reviewed when done
  After you export       for Word files, a short checklist for the PDF you make from it
"Accept as is" removes an item from the list and records your reason.

The checkbox "Show only what WCAG 2.1 AA requires" hides WCAG 2.2 and best practice items.


AI REVIEW OF MANUAL CHECKS (optional)

ADA Checker can ask Claude to judge the "Check manually" items for you: it compares each
picture with its alt text, reads the math, checks reading order and color use, and tests
web pages for zoom and keyboard use in a real browser. It uses Claude Code, which comes
with a Claude Pro or Max subscription, so there is no API key and no separate bill.
Claude Code runs on your computer and the file contents are sent to Claude to review.

Set up once:
1. Open PowerShell and run:   irm https://claude.ai/install.ps1 | iex
2. Close PowerShell, open it again, type   claude   and press Enter.
   Sign in with your Claude account when asked, then type /exit.
3. In ADA Checker open Settings, press Check again, tick "Use AI review", and Save.

After that every check ends with an AI review. Items Claude is sure about are ticked
"Reviewed by AI" and logged that way in the compliance record. Items it thinks need a
change show its note and suggested fix, often new alt text you can copy. Anything it
cannot decide, and every video caption check, stays for you. You can also press
"AI review" on any result. AI can be wrong, so spot check its work and untick anything
you disagree with. When a file changes, its AI reviews are cleared and redone.

Usage comes out of the monthly Agent SDK credit that is part of your Claude plan, not your
chat limits. Sonnet (the default) uses less of it than Opus.


HISTORY AND RECORDS

The History tab shows how many files are ready now, and this month compared to last month.
"Export compliance record" saves an Excel file listing every file, its status and date,
items you reviewed, and items you accepted as is with your reasons.


KEEPING IT UP TO DATE

Run Update.bat about once a month. It updates the axe-core web rules and the
checking libraries.


PRIVACY

Everything runs on your computer. The internet is used to check that web links work
(you can turn this off in Settings), by Update.bat, and, only if you turn on AI review,
to send file contents to Claude for review.


WHAT IT CANNOT DO

No automated tool can confirm everything. Without AI review, a person needs to judge whether
alt text is accurate, whether math reads correctly in a PDF, whether reading order makes
sense, and whether videos show important things that are not spoken. Those items are listed
under Check manually so nothing is missed. AI review settles many of them, but video
captions always need a person, and AI verdicts should be spot checked.


UNINSTALL

Double click Uninstall.bat, then delete this folder.


IF SOMETHING GOES WRONG

Details of any error are saved in %LOCALAPPDATA%\ADA Checker\log.txt
